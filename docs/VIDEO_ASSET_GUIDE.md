# Video asset acquisition guide

Goal: move from “6 generated clips” to a repeatable, lawful pipeline that can process **hundreds of real videos** and produce a viewable CV+NLP result reel for each one.

> Rule: prefer datasets with explicit licenses. Do not download Premier League / TV broadcast footage from an API unless the API contract grants you the video or derivative rights. Match metadata, lineups and commentary are not broadcast-video rights. For football video demos, use **SoccerNet** below.

## 2. Action recognition at scale: UCF101 (13,320 videos, 101 actions)

Good for demonstrating action-state indexing, motion keyframes, retrieval and grounding over human activities (sports, tool use, writing, cooking, etc.).

- Official page: <https://www.crcv.ucf.edu/research/data-sets/ucf101>
- Archive: `UCF101.rar` (~6.5 GB download, much more extracted)
- Splits: <https://www.crcv.ucf.edu/research/data-sets/ucf101>

```powershell
New-Item -ItemType Directory -Force data\source | Out-Null
Invoke-WebRequest -Uri "https://www.crcv.ucf.edu/data/UCF101/UCF101.rar" -OutFile data\source\UCF101.rar
# Extract with 7-Zip / WinRAR / unrar into data\source\ucf101
```

Python alternative (needs `ffmpeg` and disk space):

```bash
pip install tensorflow-datasets
python -c "import tensorflow_datasets as tfds; tfds.load('ucf101', split='train', download=True)"
```

Use a subset first; 300 clips is plenty for a portfolio reel. Cite Soomro, Zamir & Shah (2012) when publishing results.

Warning: Kinetics is a list of YouTube URLs; some videos have disappeared. Record the access date and the number of successfully downloaded clips. Respect YouTube terms and original creators' rights.

## 4. Football / Premier-League-style analysis: SoccerNet

This is the right route for the football/sports proof you described. SoccerNet contains 550 complete broadcast games and 300k+ temporal annotations (goals, cards, substitutions, shots, replays, camera shots, dense captions, tracking). It is used for action spotting, tracking, replay grounding and VQA.

- Site: <https://www.soccer-net.org/>
- Hugging Face organisation: <https://huggingface.co/SoccerNet>
- Some raw-video repositories are **gated**: request access on the dataset page, accept the NDA, then authenticate locally.

```bash
pip install -U SoccerNet huggingface_hub datasets
hf auth login
```

Public labels/features first (no gate):

```bash
hf download SoccerNet/SN-Labels --repo-type dataset --local-dir data/source/SoccerNet/SN-Labels
hf download SoccerNet/SN-Features --repo-type dataset --local-dir data/source/SoccerNet/SN-Features
```

Gated raw broadcast videos (after approval):

```bash
hf download SoccerNet/SoccerNet_raw_HQ --repo-type dataset --local-dir data/source/SoccerNet/raw
```

Batteries-included devkit variant:

```python
from SoccerNet.Downloader import SoccerNetDownloader

downloader = SoccerNetDownloader(LocalDirectory="data/source/SoccerNet")
downloader.downloadGames(files=["Labels-v2.json"], split=["train", "valid", "test"])
# After HF access approval:
downloader.downloadGames(files=["1_224p.mkv", "2_224p.mkv"], split=["train", "valid", "test"])
```

OpenSportsLab sharded alternative (no manual unzip):

```python
from datasets import load_dataset
ds = load_dataset("OpenSportsLab/OSL-SoccerNet", revision="224p")
```

Why this beats a generic API application: the annotations give you **ground-truth timestamps for actions**, so you can show CV keyframes/anomalies and NLP claims aligning with real events, instead of only showing object boxes.

## 6. Turn any folder into 300 processed CV+NLP videos

The repository already has the glue. `tools/build_manifest_from_folder.py` creates a manifest, `tools/prepare_real_data.py` creates detection-derived timestamped JSON logs, `run_pipeline.py` runs all 10 features, and `tools/render_result_videos.py` writes a result MP4 per video.

```powershell
# 1. Manifest for up to 300 clips from any downloaded dataset folder.
python tools/build_manifest_from_folder.py --videos-dir data\source\intel-sample-videos --output config\bulk_videos_manifest.json --limit 300 --prefix intel --industry "Real public footage"

# 2. Generate real YOLO26 detection-derived event logs (NLP input).
python tools/prepare_real_data.py --manifest config\bulk_videos_manifest.json --real-dir data\source\intel-sample-videos --logs-dir data\bulk\logs --force

# 3. Run the full gated CV + NLP suite.
python run_pipeline.py --all --manifest config\bulk_videos_manifest.json --real-dir data\source\intel-sample-videos --logs-dir data\bulk\logs --output-dir outputs\bulk --model yolo26n.pt --query "person car motion action zone"

# 4. Render one viewable CV+NLP result video for every processed clip.
python tools/render_result_videos.py --manifest config\bulk_videos_manifest.json --reports-dir outputs\bulk --real-dir data\source\intel-sample-videos --logs-dir data\bulk\logs --output-dir docs\videos\bulk --contact-sheet docs\figures\bulk_contact_sheet.png --limit 300
```

Result per clip:

```text
outputs/bulk/<video_id>/report.json          all 10 feature outputs + skip reasons
docs/videos/bulk/<video_id>_cv_nlp.mp4        viewable CV+NLP analysis reel
data/bulk/logs/<source_stem>.json             detection-derived timestamped text
```

Even when a dataset clip has **no transcript**, the JSON log created in step 2 gives the NLP track real, frame-derived text. Nothing is invented.

## 7. Practical limits and troubleshooting

| Symptom | Cause | Fix |
|---|---|---|
| `REAL_VIDEO_UNREADABLE` / `moov atom not found` | Corrupt or still-downloading file | Re-download; the pipeline already skips it safely |
| `detector_mode=opencv_fallback` | Weights not found locally | Run `python tools/prepare_real_data.py --download` or pass `--model` with an existing local file |
| NLP features skipped with `NO_EVENT_TEXT` | No side-car and no detection log | Run `tools/prepare_real_data.py` for that folder first |
| `NO_TEXT_REGION` on real footage | No legible signage / no OCR binary installed | Expected; the skip reason is honest, not a failure |
| Very slow run | Large 1080p source frames | Add/keep `width: 320`, `height: 240` in manifest entries, or use `224p` SoccerNet clips |
| Huge disk use | Kinetics/UCF archives | Delete `*_targz` after extraction; process in batches of 300 |

### Attribution checklist for public demos

1. Name the dataset and source URL.
2. State its license (e.g. Intel CC BY 4.0, UCF101 research use, SoccerNet NDA).
3. Say which clips you used and that frames/overlays are derived from them.
4. Cite the dataset paper when showing benchmark-style results.
5. Keep model-weight license separate from video-source license.

The local examples are documented in [`data/real/ATTRIBUTION.md`](../data/real/ATTRIBUTION.md).
